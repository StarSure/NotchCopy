# 功能截图

截图对应 v0.4.2 的原生界面。使用独立演示数据，不读取作者或用户真实文案，不包含桌面上其他应用的窗口。

| 文件 | 展示的状态 | 来源 |
| --- | --- | --- |
| `list.png` | 三条示例文案与列表操作入口 | 实际 `NotchView` 渲染 |
| `search.png` | 输入“代码”后的搜索结果 | 实际搜索逻辑与 `NotchView` 渲染 |
| `preview.png` | 多行“会议纪要”全文预览 | 实际全文预览视图渲染 |
| `empty.png` | 新安装的空列表提示 | 实际空状态视图渲染 |
| `editor.jpg` | 新增文案窗口，填写标题和多行正文，尚未保存 | 隔离演示 App 的原生窗口截图 |

面板截图复用生产视图和控制器，以 [Examples/snippets.example.json](../../Examples/snippets.example.json) 为唯一示例数据来源，直接导出自身视图，不截取整个桌面。生成器运行在 `--demo` 模式，使用临时演示数据目录，不修改真实文案，也不注册全局快捷键。

在有桌面会话的 Mac 上，使用完整 Xcode 工具链执行：

```sh
Scripts/capture-panel-screenshots.sh
```

命令生成列表、搜索、全文预览、空列表四张图片。编辑器截图需在隔离演示实例中打开「新增文案」，填写示例标题与正文，再截取该窗口；它不由上面的面板生成器生成。

应用顶部的空白空间对应物理刘海位置。图片是界面状态说明，无法代替悬停、跨屏和滚动体验的实际验收。
