# 架构与交互约束

应用只有一个 SnippetStore 和一个 NotchController。优先在内置刘海屏创建一个透明 NSPanel；没有刘海时使用主屏。显示器参数变化后重建窗口，数据目录与存储对象保持不变。

收起状态不绘制形状、不暴露隐藏控件，根视图的点击区域为空，NSPanel 忽略鼠标事件。触发通过读取指针位置判定，不能用一块透明但接收点击的窗口冒充隐藏入口。

物理刘海的触发区是下沿中央的窄带，不延伸到上方显示器。停留阈值避免快速划过时弹出；复制或 Esc 收起后，需要离开触发区才能再次展开，避免鼠标静止导致循环弹出。

悬停展开不获取键盘。用户点击输入或通过快捷键、菜单主动打开时才获取键盘；主动呼出后自动聚焦搜索框；手动展开或全文预览保持打开，Esc 或点击其他应用可关闭。

复制流程为：写入系统剪贴板 → 显示短暂反馈 → 放弃键盘 → 开始收起动画 → 关闭点击区域并释放 key window → 在合适时恢复原应用。若用户已主动切到另一应用，不能将焦点抢回旧应用。延迟操作使用 generation 检查，避免旧关闭任务影响新展开的面板。

SnippetStore 在修改前重读文件；读取失败时不覆盖原文件。写入采用原子替换。每日首次修改前保存一份旧文件到本机 Backups，示例或截图模式使用临时目录。

`--demo --show` 可启动独立示例数据，用于截图和界面验收，不读取或修改真实文案。此模式不是默认用户流程。

没有网络客户端、私有媒体框架、事件 tap 或自动粘贴。全局快捷键使用 Carbon 注册；普通复制使用 NSPasteboard。编辑器使用标准 AppKit 窗口承载 SwiftUI，以保持中文输入法、多行编辑和标准编辑快捷键可用。
